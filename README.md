# PC-Star

Boutique pickup **PC Star Informatique** (El Makari Les Castors, Oran).

## Run

```bash
npm install
npm run dev
npm test
npm run build
```

## Features

- AR / FR / EN (Arabic default, RTL)
- Light / dark / system theme + customer accent colors
- Master: desk list, add/hide products, delete customers, panels
- Customers: profile avatars, cart reserve with DZ mobile validation (Mobilis/Ooredoo/Djezzy)
- Demo-only auth in the browser — not production security
